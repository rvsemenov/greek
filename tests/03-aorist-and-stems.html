Αόριστος & Μέλλοντας Απλός ⚡

Правила из шапки таблицы + неправильные глаголы

1) -νω, -ζω, -θω → -σα: τελειώνω → τελείωσα, αγοράζω → αγόρασα, ντύνω → έντυσα
2) -κω, -γω, -χω, -σκω, -χνω → -ξα: ανοίγω → άνοιξα (и ряд глаголов на -ζω: αλλάζω → άλλαξα, παίζω → έπαιξα, κοιτάζω → κοίταξα, φωνάζω → φώναξα)
3) -πω, -βω, -φω, -πτω → -ψα: βάφω → έβαψα, ανάβω → άναψα, κλαίω → έκλαψα
4) -εύω → -εψα: παντρεύω → πάντρεψα, ανακατεύω → ανακάτεψα
5) Приращение и ударение: если 2 слога — добавляем в начале έ-, ударение на 3-м слоге с конца (в Μέλλοντας Απλός «έ-» убирается: έγραψα → θα γράψω)
6) 2 спряжение (Β1/Β2): основа + -ησα / -ασα / -εσα / -ηξα (νικώ → νίκησα, γελώ → γέλασα, φορώ → φόρεσα)
