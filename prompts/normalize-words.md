# Промпт: нормализовать словарь

**Вход:** сырые файлы `source/words/b1_*.txt`.
**Выход:** `source/words/B1/{verbs,nouns,adjectives,other}.csv`.

---

## Что в сырых файлах

`b1_anki.txt` — главный источник, TSV из трёх колонок:

```
το αβγό / το αυγό	яйцо (Τρώω ένα αβγό - Я ем яйцо)	noun
αγαπάω & αγαπώ	любить (αγάπησα - я полюбил; Σ' αγαπώ - Я тебя люблю)	verb
αγαπημένος, -η, -ο	любимый (Ο αγαπημένος μου φίλος - Мой любимый друг)	adj
```

Что нужно разобрать:

| В сыром виде | Куда |
|---|---|
| `το αβγό` | `article` = `το`, `lemma` = `αβγό` |
| `αβγό / αυγό`, `αγαπάω & αγαπώ` | `lemma` = первое, `alt` = второе |
| `αγαπημένος, -η, -ο` | `lemma` + `fem` + `neut` (развернуть окончания целиком) |
| `любить (αγάπησα - я полюбил; …)` | `ru` = `любить`, формы и примеры — по своим колонкам |
| `αγάπησα - я полюбил` в скобках | `aorist` = `αγάπησα` |
| `Σ' αγαπώ - Я тебя люблю` в скобках | `example_gr` + `example_ru` |

`b1_words_article.txt` (4128 строк) — полный список с артиклями, шире чем `b1_anki.txt` (389).
Использовать как источник недостающих лемм и артиклей.

---

## Целевые форматы

```csv
# verbs.csv
lemma,alt,ru,aorist,future,passive,passive_aorist,root,level,theme,example_gr,example_ru

# nouns.csv
lemma,article,gen_sg,nom_pl,gen_pl,ru,root,level,theme,example_gr,example_ru

# adjectives.csv
lemma,fem,neut,ru,comparative,root,level,theme,example_gr,example_ru

# other.csv
lemma,pos,ru,level,theme,example_gr,example_ru
```

`pos` в `other.csv`: `adv`, `prep`, `conj`, `particle`, `phrase`, `num`, `pron`.

## Правила разбора

1. **Механическое — скриптом.** Разделение колонок, вынос артикля, разбор `/` и `&`,
   разворачивание `-η, -ο` в полные формы, выделение содержимого скобок. Скрипт кладётся
   в `tools/`, чтобы прогон был воспроизводим.
2. **Формы глаголов — агентом.** Аорист часто есть прямо в скобках примера — взять оттуда.
   Остальное дозаполнить, **отдельно пометив неправильные глаголы**: у них формы не выводятся
   по правилу и ошибка здесь дороже всего (`πηγαίνω → πήγα`, `βλέπω → είδα`, `τρώω → έφαγα`).
3. **Падежи существительных — по типу склонения**, не наугад. Тип определяется окончанием
   и родом; если случай спорный (`η πόλη → των πόλεων`, не `των πολών`) — проверить, а не
   угадать.
4. **`root`** — общий корень семьи слов: `αγαπάω`, `αγάπη`, `αγαπημένος` → `αγαπ-`.
   Если семьи нет, оставить пустым. Не выдумывать корни ради заполненности.
5. **`theme`** — одно слово латиницей: `food`, `family`, `travel`, `work`, `health`, `city`,
   `feelings`, `time`, `nature`, `school`. Держать список коротким.
6. **Дубли.** `αβγό` и `αυγό` — одно слово в двух написаниях, это `lemma` + `alt`,
   а не две строки.

## Чего не делать

- Не выбрасывать слова, которые не удалось разобрать. Собрать их в `source/words/B1/_todo.txt`
  с исходной строкой и причиной — разберутся руками.
- Не заполнять колонку догадкой, если форма неизвестна: лучше пустое поле, чем неверная форма
  в тесте. Пустое видно валидатору, неверное — нет.
- Не менять переводы по своему вкусу: это выученные формулировки из Anki.
