# Промпт: сгенерировать тест по правилу

**Вход:** id правила (например `A2/01-aorist-conj1`), опционально число вопросов (по умолчанию 30).
**Выход:** файл `tests/<уровень>/<номер-тема>.json`.

---

## Шаги

1. Прочитать `source/rules/<id>.md` **целиком**, включая раздел «Типичные ошибки» — он главный
   источник идей для дистракторов.
2. Прочитать словарь уровня и ниже: `source/words/<уровень>/*.csv`.
3. Прочитать эталон `tests/A2/01-aorist-conj1.json`, чтобы совпасть по стилю и уровню
   сложности. Если эталона ещё нет — значит, это первый тест в проекте: сделать его
   особенно аккуратно, дальше по нему будут равняться остальные.
4. Сгенерировать вопросы по схеме ниже.
5. Прогнать `python3 tools/check-tests.py tests/<уровень>/<файл>.json` и починить всё, что
   не прошло. Не отдавать результат, пока валидатор не зелёный.
6. Коротко отчитаться: сколько вопросов, как распределены по типам и подтемам.

---

## Схема файла

```json
{
  "rule": "A2/01-aorist-conj1",
  "title": "Αόριστος 1-го спряжения",
  "level": "A2",
  "items": [
    {
      "id": "a2-01-0001",
      "type": "choice",
      "prompt": "Χθες ___ ένα βιβλίο στο βιβλιοπωλείο.",
      "options": ["αγοράζω", "αγόρασα", "θα αγοράσω", "αγόραζα"],
      "answer": "αγόρασα",
      "why": "«Χθες» + однократное законченное действие → αόριστος. «αγόραζα» — παρατατικός, это «покупал регулярно».",
      "words": ["αγοράζω", "βιβλίο"],
      "tags": ["aorist", "time-markers"]
    },
    {
      "id": "a2-01-0002",
      "type": "inflect",
      "prompt": "γράφω → αόριστος, 1-е лицо ед. ч.",
      "answer": "έγραψα",
      "accept": ["έγραψα"],
      "why": "-φω → -ψα; слогов всего два, поэтому добавляется приращение έ-.",
      "words": ["γράφω"],
      "tags": ["aorist", "augment"]
    }
  ]
}
```

### Поля

| Поле | Обязательно | Что в нём |
|---|---|---|
| `id` | да | `<уровень>-<номер правила>-<4 цифры>`, строчными, сквозная нумерация внутри файла |
| `type` | да | `choice`, `inflect`, `cloze`, `article`, `translate` |
| `prompt` | да | Задание. Пропуск обозначается `___` (три подчёркивания) |
| `options` | для `choice`, `article` | Ровно 4 варианта, порядок произвольный — приложение перемешает |
| `answer` | да | Правильный ответ. Для `choice` обязан быть одним из `options` |
| `accept` | для ввода с клавиатуры | Все принимаемые написания, включая `answer` |
| `why` | да | Разбор **этой** ошибки: 1–2 предложения, по-русски |
| `words` | да | Леммы использованных слов — по ним считается покрытие словаря |
| `tags` | да | Только теги из словаря `tools/check-rules.py`, обычно подмножество тегов правила |

## Требования к содержанию

### Лексика

- Брать слова **только** из `source/words/` своего уровня или ниже. Новая лексика в
  грамматическом тесте — это проверка словаря, а не правила.
- Если для хорошего примера не хватает слова — добавить его в соответствующий CSV в том же
  коммите, а не выдумывать молча.
- Никаких имён собственных и редких слов ради красоты примера.

### Дистракторы (неправильные варианты)

Хороший дистрактор — тот, который реально можно выбрать. Правила:

- та же часть речи, та же форма записи, сопоставимая длина;
- соседние времена того же глагола (ενεστώτας / παρατατικός / αόριστος / μέλλοντας) — лучший
  источник для тестов на времена;
- слова того же корня (колонка `root` в CSV);
- типичные ошибки русскоязычных из раздела «Типичные ошибки» в правиле;
- **запрещено:** два варианта, подходящих по смыслу; варианты, отличающиеся только
  опечаткой; варианты из другой части речи; «очевидно левый» вариант для массовки.

### Распределение

- Покрыть **все** подразделы правила, а не один самый простой. Если в правиле три таблицы
  окончаний — вопросы должны затрагивать все три.
- Внутри файла: примерно 60% `choice`, 40% с вводом (`inflect` / `cloze`). Для правил про
  артикли и падежи добавить `article`.
- От простого к сложному: первые 5 вопросов — на узнавание, последние 5 — на применение
  в контексте предложения.

### Поле `why`

Это то, что человек читает в момент ошибки. Требования:

- объяснять, почему верен правильный вариант **и** почему не подходит типичный неверный;
- не пересказывать правило целиком — для этого есть кнопка «Правило»;
- по-русски, 1–2 предложения, без воды;
- плохо: «Здесь нужен аорист». Хорошо: «„Χθες“ + однократное действие → аорист. „αγόραζα“ —
  παρατατικός, это „покупал регулярно“».

### Греческий текст

- Ударения обязательны во всех многосложных словах.
- Конечная сигма `ς` только в конце слова, в остальных позициях `σ`.
- Только греческие буквы: не писать латинскую `o` вместо `ο`, `v` вместо `ν`, `p` вместо `ρ`;
  не использовать `µ` (U+00B5) вместо `μ` (U+03BC).
- Предложения живые и короткие: так, как реально говорят, а не «Ο κήπος του θείου μου».

---

## Чего не делать

- Не трогать файлы правил и словарей, кроме добавления недостающих слов.
- Не переиспользовать `id` из других файлов.
- Не генерировать больше запрошенного «про запас».
- Не отдавать результат с красным валидатором.
