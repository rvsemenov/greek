## Когда используется

Предложение («давай…»), разрешение («пусть…»), пожелание («хоть бы…», «будь здоров»),
предложение услуги («открыть окно?»), вероятность («может быть», «должно быть», «наверное»).

## Образование

| Конструкция | Значение | Пример |
|---|---|---|
| **ας** + να-форма (1-е л. мн.) | давай(те) | Ας πάμε! |
| **ας** + να-форма (3-е л.) | пусть | Ας περιμένει. |
| **ας** + имперфект | упрёк о прошлом: «…бы раньше!» | Ας μου το έλεγες νωρίτερα! |
| **μακάρι να** + να-форма | хоть бы, вот бы (реально) | Μακάρι να έρθει! |
| **μακάρι να** + имперфект | вот бы (нереально сейчас) | Μακάρι να ήμουν στη θάλασσα. |
| **να** + форма (без главного глагола) | пожелание / «мне сделать?» | Να είσαι καλά! / Να ανοίξω το παράθυρο; |
| **μπορεί να** | может быть, возможно | Μπορεί να βρέξει. |
| **πρέπει να** | должен; должно быть (вероятность) | Πρέπει να είναι κουρασμένη. |
| **έπρεπε να** | надо было, следовало | Έπρεπε να μου το πεις. |
| **θα** + настоящее / прошедшее | наверное (догадка) | Θα είναι στο σπίτι. / Θα έφυγε. |

- **μπορεί** (возможно) и **πρέπει** — безличные, не спрягаются. Сравни: **μπορώ** να έρθω — я могу прийти; **μπορεί** να έρθω — может быть, приду.
- Вероятность в прошлом: **μπορεί να έφυγε**, **πρέπει να έχει φύγει** — может быть / должно быть, ушёл.
- Отрицание: **ας μην**, **μακάρι να μην**, **να μην**.
- Наречия: ίσως (может быть), μάλλον (скорее всего), σίγουρα (точно), πιθανόν (вероятно).

## Примеры

- **Ας πάμε σινεμά απόψε!** — Давай сходим в кино сегодня вечером!
- **Ας περιμένει λίγο.** — Пусть немного подождёт.
- **Μακάρι να κερδίσουμε!** — Хоть бы мы выиграли!
- **Να είσαι καλά!** — Спасибо! (букв. «будь здоров»)
- **Να κλείσω την πόρτα;** — Закрыть дверь?
- **Μπορεί να αργήσω λίγο.** — Я, может быть, немного опоздаю.
- **Πρέπει να είναι κουρασμένη, δούλεψε όλη μέρα.** — Она, должно быть, устала: весь день работала.
- **Θα είναι περίπου εννιά.** — Сейчас, наверное, около девяти.

## Типичные ошибки

- *Μπορώ να βρέξει* ≠ **Μπορεί να βρέξει** — «возможно» выражается безличным μπορεί.
- *Πρέπω να φύγω* ≠ **Πρέπει να φύγω** — πρέπει всегда в 3-м лице ед. ч.
- *Ας πηγαίνουμε* ≠ **Ας πάμε** — разовое предложение → форма аориста.
- *Μακάρι θα έρθει* ≠ **Μακάρι να έρθει** — после μακάρι нужно να.
- *Ας δεν αργήσουμε* ≠ **Ας μην αργήσουμε** — отрицание μην.
- *μάλλον* — это «скорее всего», а не «больше» (больше = περισσότερο).
