## Когда используется

«Перед тем как…», «после того как…», «как только…», «пока…», «пока не…», «чтобы…».
Главное — какая форма глагола после каждого союза.

## Образование

### Время

| Союз | Значение | Форма глагола |
|---|---|---|
| όταν | когда | о будущем — форма как после να (όταν **τελειώσω**) |
| **πριν (να)** | перед тем как | **всегда** форма как после να, даже о прошлом |
| αφού | после того как | о прошлом — аорист/плюсквамперфект; о будущем — να-форма |
| μόλις | как только | о прошлом — аорист; о будущем — να-форма |
| ενώ | в то время как, пока | обычно имперфект / настоящее |
| καθώς | (в то время) как | обычно имперфект / настоящее |
| **μέχρι να** / ώσπου να | пока не, до тех пор пока | να-форма, **без отрицания** |
| από τότε που | с тех пор как | изъявительное |
| κάθε φορά που | каждый раз, когда | изъявительное; о будущем — να-форма |

О будущем после όταν, μόλις, αφού, πριν, μέχρι в нормативном языке **θα не ставится**.

### Цель

| Союз | Значение | Пример |
|---|---|---|
| **για να** (+ για να μην) | чтобы | Ήρθα για να σε δω. |
| να (после глаголов движения) | чтобы | Πάω να φέρω ψωμί. |
| ώστε να / έτσι ώστε να | так, чтобы | Μίλα δυνατά, ώστε να σε ακούνε όλοι. |

Инфинитива нет: «чтобы выучить» → **για να μάθω / μάθεις / μάθουμε** — глагол спрягается.
Следствие «так…, что» (τόσο… ώστε/που + изъявительное) — в B2/09-concessive-causal-result.

## Примеры

- **Πριν βγεις, πάρε ομπρέλα.** — Перед тем как выйти, возьми зонт.
- **Πριν φύγει, μου έδωσε τα κλειδιά.** — Перед уходом он отдал мне ключи.
- **Αφού έφαγε, ξάπλωσε λίγο.** — Поев, он немного прилёг.
- **Μόλις τελειώσω, θα σου τηλεφωνήσω.** — Как только закончу, позвоню тебе.
- **Ενώ διάβαζα, χτύπησε το κουδούνι.** — Пока я читал, позвонили в дверь.
- **Θα μείνω εδώ μέχρι να σταματήσει η βροχή.** — Я останусь здесь, пока не кончится дождь.
- **Ήρθα στην Ελλάδα για να μάθω ελληνικά.** — Я приехал в Грецию, чтобы выучить греческий.
- **Από τότε που μετακόμισα, κοιμάμαι καλύτερα.** — С тех пор как я переехал, я лучше сплю.

## Типичные ошибки

- *πριν έφυγε*, *πριν φεύγεις* ≠ **πριν φύγει**, **πριν φύγεις** — после πριν всегда να-форма аориста.
- *Όταν θα τελειώσω, θα σου πω* ≠ **Όταν τελειώσω, θα σου πω** — в придаточном времени о будущем θα не нужно.
- *Θα περιμένω μέχρι να μην έρθεις* ≠ **μέχρι να έρθεις** — русское «пока не» по-гречески без отрицания.
- *για να δεν αργήσουμε* ≠ **για να μην αργήσουμε** — после να отрицание μην.
- *Ήρθαμε για να μάθω* ≠ **για να μάθουμε** — лицо глагола после για να согласуется по смыслу, инфинитива нет.
- αφού «после того как» ≠ αφού «раз уж»: **Αφού δεν θέλεις, δεν πάμε** — Раз не хочешь, не идём.
