## Когда используется

Глаголы на -ομαι/-άμαι после να (θέλω να ξεκουραστώ) и в повелительном (ντύσου! κάθισε!).
Это в основном возвратные и депоненты: одеваться, вставать, садиться, отдыхать, вспоминать, торопиться.

## Образование

### να + форма

| Разовое (основа аориста) | Длительное (настоящее) |
|---|---|
| να γραφτώ, να γραφτείς, να γραφτεί, να γραφτούμε, να γραφτείτε, να γραφτούν | να γράφομαι, να γράφεσαι… |

Формы = будущее без θα: θα ντυθώ → να ντυθώ, θα θυμηθώ → να θυμηθώ.
Депоненты с активным аористом: να έρθω, να γίνω, να καθίσω / να κάτσω.

### Повелительное (разовое)

Ед. ч.: основа активного аориста + **-ου**. Мн. ч. = форма να на -θείτε / -στείτε.

| Глагол | εσύ | εσείς |
|---|---|---|
| ντύνομαι (одеваться) | ντύσου | ντυθείτε |
| ετοιμάζομαι (собираться) | ετοιμάσου | ετοιμαστείτε |
| ξεκουράζομαι (отдыхать) | ξεκουράσου | ξεκουραστείτε |
| χτενίζομαι (причёсываться) | χτενίσου | χτενιστείτε |
| βιάζομαι (торопиться) | βιάσου | βιαστείτε |
| παντρεύομαι (жениться) | παντρέψου | παντρευτείτε |
| θυμάμαι (помнить) | θυμήσου | θυμηθείτε |
| κοιμάμαι (спать) | κοιμήσου | κοιμηθείτε |
| σκέφτομαι (думать) | σκέψου | σκεφτείτε |
| σηκώνομαι (вставать) | **σήκω** / σηκώσου | σηκωθείτε |
| κάθομαι (садиться) | **κάθισε** / κάτσε | **καθίστε** / κάτσετε |
| έρχομαι (приходить) | **έλα** | **ελάτε** |
| γίνομαι (становиться) | **γίνε** | **γίνετε** |

### Запрет: μη(ν) + να-форма

- **μη + настоящее** — «не делай (вообще, сейчас)»: **Μη φοβάσαι.** **Μη βιάζεσαι.**
- **μη + аорист** — «смотри, не сделай (разово)»: **Μη φοβηθείς.** **Μην ξεχαστείς.**

## Примеры

- **Ντύσου γρήγορα, αργήσαμε!** — Одевайся быстрее, мы опаздываем!
- **Σήκω, είναι ήδη οκτώ!** — Вставай, уже восемь!
- **Καθίστε, παρακαλώ.** — Садитесь, пожалуйста.
- **Θυμήσου τι σου είπα.** — Вспомни, что я тебе сказал.
- **Σκέψου το καλά.** — Хорошенько подумай об этом.
- **Μη φοβάσαι, ο σκύλος δεν δαγκώνει.** — Не бойся, собака не кусается.
- **Θέλω να ξεκουραστώ λίγο.** — Я хочу немного отдохнуть.
- **Πρέπει να ετοιμαστούμε για το ταξίδι.** — Нам надо собраться в поездку.

## Типичные ошибки

- *Ντύσε!* (одень кого-то) ≠ **Ντύσου!** (оденься) — актив ντύνω = одевать другого, пассив ντύνομαι = одеваться.
- *Μη φοβήσου* ≠ **Μη φοβάσαι** / **Μη φοβηθείς** — с μη повелительная форма не используется.
- *Θέλω να ξεκουράσω* ≠ **Θέλω να ξεκουραστώ** — ξεκουράζω = давать отдых кому-то, «отдохнуть самому» — пассив.
- *κάθισου* ≠ **κάθισε** / **κάτσε** — у κάθομαι повелительное активной формы.
- *ελάστε* ≠ **ελάτε** — мн. ч. от έλα.
