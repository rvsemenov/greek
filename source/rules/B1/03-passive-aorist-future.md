## Когда используется

Аорист и простое будущее глаголов на -ομαι/-άμαι: и настоящего пассива («книга была написана»),
и возвратных/депонентов («я оделся», «я устал», «я вспомнил»).

## Образование

### Окончания

| | Αόριστος | Μέλλοντας Απλός |
|---|---|---|
| εγώ | γράφτηκα | θα γραφτώ |
| εσύ | γράφτηκες | θα γραφτείς |
| αυτός | γράφτηκε | θα γραφτεί |
| εμείς | γραφτήκαμε | θα γραφτούμε |
| εσείς | γραφτήκατε | θα γραφτείτε |
| αυτοί | γράφτηκαν | θα γραφτούν(ε) |

Ударение в аористе — на 3-м слоге с конца (γράφτηκα → γραφτήκαμε). В будущем — всегда на окончании.
Основа будущего = аорист без -ηκα + -ώ: γράφτ|ηκα → γραφτ|ώ.

### Основа по активному аористу

| Активный аорист | Пассивный аорист | Примеры |
|---|---|---|
| -σα (от -ζω) | -στηκα | αγοράζω → αγοράστηκα, ετοιμάζομαι → ετοιμάστηκα, κουράζομαι → κουράστηκα |
| -σα (от -νω) | -θηκα | ντύνω → ντύθηκα, πληρώνω → πληρώθηκα |
| -ξα | -χτηκα | μπλέκω → μπλέχτηκα, διώχνω → διώχτηκα, δέχομαι → δέχτηκα |
| -ψα | -φτηκα | γράφω → γράφτηκα, κρύβω → κρύφτηκα, σκέφτομαι → σκέφτηκα |
| -εψα (от -εύω) | -εύτηκα | παντρεύω → παντρεύτηκα, μαζεύω → μαζεύτηκα |
| -ησα (2-е спр.) | -ήθηκα | αγαπώ → αγαπήθηκα, ρωτάω → ρωτήθηκα, πουλάω → πουλήθηκε |
| -ασα (2-е спр.) | -άστηκα | ξεχνάω → ξεχάστηκα, γελάω → γελάστηκα (меня обманули) |

Подробнее о пассиве 2-го спряжения — в B2/04-passive-conj2.

### Аорист частых депонентов

| Настоящее | Аорист | Будущее |
|---|---|---|
| έρχομαι | **ήρθα** | θα έρθω |
| γίνομαι | **έγινα** | θα γίνω |
| κάθομαι | **κάθισα** / έκατσα | θα καθίσω / θα κάτσω |
| σκέφτομαι | σκέφτηκα | θα σκεφτώ |
| θυμάμαι | θυμήθηκα | θα θυμηθώ |
| φοβάμαι | φοβήθηκα | θα φοβηθώ |
| κοιμάμαι | κοιμήθηκα | θα κοιμηθώ |
| χρειάζομαι | χρειάστηκα | θα χρειαστώ |
| αισθάνομαι | αισθάνθηκα | θα αισθανθώ |

έρχομαι, γίνομαι, κάθομαι в аористе спрягаются как активные: ήρθα, ήρθες, ήρθε…

## Примеры

- **Το βιβλίο γράφτηκε το 1950.** — Книга была написана в 1950 году.
- **Παντρευτήκαμε πέρσι το καλοκαίρι.** — Мы поженились прошлым летом.
- **Ντύθηκα γρήγορα και έφυγα.** — Я быстро оделся и ушёл.
- **Χθες κουράστηκα πολύ.** — Вчера я очень устал.
- **Δεν θυμήθηκα το όνομά του.** — Я не вспомнил его имя.
- **Το σπίτι πουλήθηκε σε έναν μήνα.** — Дом продали за месяц.
- **Θα το σκεφτώ και θα σου πω.** — Я подумаю и скажу тебе.

## Исключения

- κόβομαι → **κόπηκα** (а не *κόφτηκα*).
- έρχομαι, γίνομαι, κάθομαι — активные формы аориста (см. таблицу).

## Типичные ошибки

- *ερχόθηκα*, *γινόθηκα* ≠ **ήρθα**, **έγινα** — у этих депонентов аорист активной формы.
- *γράψτηκα* ≠ **γράφτηκα** — перед -τηκα ψ превращается в φ: -ψα → -φτηκα.
- *ντύστηκα* ≠ **ντύθηκα** — глаголы на -νω дают -θηκα, а не -στηκα.
- *παντρέφτηκα* ≠ **παντρεύτηκα** — у -εύω сохраняется написание ευ.
- *γράφτηκαμε* ≠ **γραφτήκαμε** — ударение остаётся на 3-м слоге с конца.
- *θα γράφτω*, *θα γραφτήσω* ≠ **θα γραφτώ** — в будущем ударное окончание -ώ, -είς, -εί…
