## Когда используется

Инфинитива в греческом нет. Там, где в русском «хочу **делать**», «могу **прийти**», «надо **читать**»,
по-гречески второй глагол стоит **в личной форме** после частицы **να**: **θέλω να διαβάζω** —
букв. «хочу, чтобы я читал». Тот же **να** переводит русское «чтобы».

## Образование

**главный глагол + να + второй глагол в нужном лице**

| Конструкция | Значение | Пример |
|---|---|---|
| **θέλω να** | хочу | **Θέλω να μένω στην Ελλάδα.** — Я хочу жить в Греции. |
| **μπορώ να** | могу | **Μπορείς να μιλάς πιο αργά;** — Можешь говорить медленнее? |
| **πρέπει να** | надо, должен | **Πρέπει να διαβάζω κάθε μέρα.** — Мне надо читать каждый день. |
| **ξέρω να** | умею | **Ξέρεις να οδηγείς;** — Ты умеешь водить? |
| **αρχίζω να** | начинаю | **Αρχίζω να καταλαβαίνω.** — Я начинаю понимать. |
| **μου αρέσει να** | мне нравится | **Μου αρέσει να διαβάζω.** — Мне нравится читать. |

- Оба глагола спрягаются: **θέλω να μένω, θέλεις να μένεις, θέλουμε να μένουμε**.
- Разные лица = русское «чтобы»: **Θέλω να μένεις εδώ.** — Я хочу, чтобы ты жил здесь.
- **πρέπει** — безличный, не меняется: **πρέπει να δουλεύω / να δουλεύεις / να δουλεύουμε**. «Надо было» — **έπρεπε να**.
- Отрицание главного глагола — **δεν**: **Δεν θέλω να…**; отрицание после να — **μην**: **να μην…**

### Настоящее или аорист после να

Форма настоящего времени после να — для процесса, привычки, умения: **ξέρω να κολυμπάω**,
**πρέπει να διαβάζω κάθε μέρα**. Для однократного действия грек берёт другую форму — основу
аориста: **θέλω να πάω, θέλω να φάω, θέλω να γράψω** (A2/07-subjunctive-na). Пока эти частые
сочетания стоит запомнить как готовые фразы.

## Примеры

- **Θέλω να μιλάω ελληνικά καλά.** — Я хочу хорошо говорить по-гречески.
- **Πρέπει να δουλεύω πολύ.** — Мне надо много работать.
- **Ξέρεις να κολυμπάς;** — Ты умеешь плавать?
- **Θέλουμε να μένουμε κοντά στη θάλασσα.** — Мы хотим жить у моря.
- **Προσπαθώ να μην τρώω γλυκά.** — Стараюсь не есть сладкое.
- **Δεν μπορώ να δουλεύω με μουσική.** — Я не могу работать под музыку.

## Типичные ошибки

- *Θέλω μιλάω*, *Θέλω μιλάω ελληνικά* ≠ **Θέλω να μιλάω**: без να нельзя.
- Не то лицо после να: *Θέλεις να μιλάω;* значит «хочешь, чтобы **я** говорил?»; «ты хочешь говорить?» — **Θέλεις να μιλάς;**
- *πρέπω, πρέπεις* ≠ **πρέπει**: глагол безличный, лицо показывает второй глагол.
- *Θέλω να δεν πάω* ≠ **Θέλω να μην πάω**: после να — **μην**, не δεν.
- «чтобы» через ότι: *Θέλω ότι διαβάζεις* ≠ **Θέλω να διαβάζεις**.
