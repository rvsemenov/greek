## Когда используется

Чтобы понимать незнакомые слова по частям и угадывать род существительного по суффиксу. Семьи однокоренных слов (колонка `root` в словаре) — основа для упражнений «собери семью слов».

## Образование

### Приставки

| Приставка | Значение | Примеры |
|---|---|---|
| ξανα- | снова, пере- | ξαναδιαβάζω (перечитываю), ξαναρωτάω (переспрашиваю) |
| ξε- | раз-, от- (обратное действие) | ξεκλειδώνω (отпираю), ξεντύνομαι (раздеваюсь), ξεπαγώνω (размораживаю) |
| παρα- | слишком, пере- | παρατρώω (переедаю), παρακοιμάμαι (просыпаю); παραλίγο — чуть не |
| υπερ- | сверх-, пере- | υπερβολή (преувеличение), υπεραγορά (супермаркет), υπερτιμώ (переоцениваю) |
| αντι- | против, взамен | αντίθετος (противоположный), αντιγράφω (списываю), αντικαθιστώ (заменяю) |
| συν- / συμ- / συλ- / συ- | вместе, со- | συνάδελφος (коллега), συμμαθητής (одноклассник), συλλέγω (собираю), συζητάω (обсуждаю) |
| προ- | пред-, заранее | προβλέπω (предвижу), προπληρώνω (плачу вперёд), προχθές (позавчера) |
| α- / αν- | не-, без- | άγνωστος (неизвестный), άχρηστος (бесполезный), ανίκανος (неспособный) |
| κακο- / καλο- | плохо / хорошо | κακοκαιρία (непогода), καλοψημένος (хорошо прожаренный) |

### Суффиксы — суффикс определяет род

| Суффикс | Род | Что образует | Примеры |
|---|---|---|---|
| -ση, -ξη, -ψη | ж. | действие | λύνω → λύση, συζητάω → συζήτηση, αποφασίζω → απόφαση, εξηγώ → εξήγηση |
| -σμός | м. | процесс (от -ίζω) | καθαρίζω → καθαρισμός, ορίζω → ορισμός, χωρίζω → χωρισμός |
| -μα | ср. | результат | γράφω → γράμμα, διαβάζω → διάβασμα |
| -ιμο | ср. | действие (разг.) | τρέχω → τρέξιμο, πλένω → πλύσιμο, ντύνω → ντύσιμο |
| -τής / -της, -τρια | м. / ж. | деятель | μαθητής / μαθήτρια, χορευτής / χορεύτρια, παίκτης |
| -τήριο | ср. | место | δικαστήριο (суд), εργαστήριο (мастерская), φροντιστήριο (курсы) |
| -ικός | прил. | относящийся к | ελληνικός, οικονομικός, ιστορικός |
| -άκι | ср. | уменьшительное | σπίτι → σπιτάκι, η γάτα → το γατάκι, κρασί → κρασάκι |
| -ούλα, -ίτσα, -ούλης | ж. / м. | уменьшительное | γάτα → γατούλα, κούκλα → κουκλίτσα, μικρός → μικρούλης |

### Семьи однокоренных слов

| Корень | Слова |
|---|---|
| γραφ- / γραπ- / γραμ- | γράφω, γραφείο, γράμμα, γραμματέας, γραπτός, περιγραφή, υπογραφή, φωτογραφία |
| λυ- | λύνω, λύση, ανάλυση (анализ), διάλυση (растворение, роспуск) |
| μαθ- | μαθαίνω, μάθημα, μαθητής, μάθηση (обучение), μαθηματικά |
| ζω- | ζω, ζωή, ζώο, ζωντανός (живой), ζωηρός (бойкий) |

## Примеры

- **Ξαναδιάβασα το γράμμα τρεις φορές.** — Я перечитал письмо три раза.
- **Βρήκαμε μια λύση μετά από πολλή συζήτηση.** — Мы нашли решение после долгого обсуждения.
- **Παρακοιμήθηκα και έχασα το λεωφορείο.** — Я проспал и опоздал на автобус.
- **Ξεκλείδωσε την πόρτα, σε παρακαλώ.** — Отопри дверь, пожалуйста.
- **Οι συνάδελφοί μου είναι πολύ συνεργάσιμοι.** — Мои коллеги всегда готовы помочь.
- **Ήπιαμε ένα κρασάκι στην ταβέρνα.** — Мы выпили винца в таверне.

## Типичные ошибки

- *η γατάκι* → **το γατάκι**; *ο σκυλάκι* → **το σκυλάκι** — уменьшительные на -άκι всегда среднего рода.
- *ο λύση, η καθαρισμός, η γράμμα* → **η λύση, ο καθαρισμός, το γράμμα** — -ση всегда ж. р., -σμός — м. р., -μα — ср. р.
- *ξαναέγραψα* → **ξανάγραψα** — приращение έ- исчезает: ударение уже на приставке.
- *συνζητάω, συνμαθητής* → **συζητάω, συμμαθητής** — ν в συν- уподобляется (συμ-, συλ-) или выпадает (συ-ζ).
- *αέντιμος* → **ανέντιμος** — перед гласной α- становится αν-.
