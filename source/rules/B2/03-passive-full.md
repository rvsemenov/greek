## Когда используется

Формы на -ομαι — это не только пассив. У них четыре значения, и их надо различать:

| Значение | Пример | Перевод |
|---|---|---|
| Пассив | **Το σπίτι χτίστηκε το 1950.** | Дом был построен в 1950 году. |
| Возвратное (себя) | **Ντύνομαι γρήγορα.** | Я быстро одеваюсь. |
| Взаимное (друг друга) | **Βλεπόμαστε κάθε Κυριακή.** | Мы видимся каждое воскресенье. |
| Депонент (актива нет) | **Έρχομαι, εργάζομαι, χρειάζομαι.** | Прихожу, работаю, нуждаюсь. |

## Образование: полная схема (γράφομαι)

| Время | Форма | Как строится |
|---|---|---|
| Ενεστώτας | γράφομαι | основа настоящего + -ομαι |
| Παρατατικός | γραφόμουν(α) | основа настоящего + -όμουν |
| Αόριστος | γράφτηκα | пассивная основа + -ηκα |
| Μέλλοντας Συνεχής | θα γράφομαι | θα + настоящее |
| Μέλλοντας Απλός | θα γραφτώ | θα + пассивная основа + -ώ |
| Παρακείμενος | έχω γραφτεί | έχω + пассивная основа + -εί |
| Υπερσυντέλικος | είχα γραφτεί | είχα + -εί |
| Συντελεσμένος μέλλοντας | θα έχω γραφτεί | θα έχω + -εί |
| Υποτακτική | να γράφομαι / να γραφτώ | να + наст. / να + пасс. основа |
| Προστακτική | γράψου / γραφτείτε | |
| Μετοχή | γραμμένος | -μένος |

Форма на **-εί** = Μέλλοντας Απλός 3 л. ед. ч. без θα: θα γραφτεί → έχει γραφτεί, θα πουληθεί → έχει πουληθεί.

**Действие или состояние.** έχει + -εί — действие совершено; είναι + -μένος — результат, состояние:
**Τα εισιτήρια έχουν πουληθεί** (их распродали) / **Τα εισιτήρια είναι πουλημένα** (они проданы, их нет).

## Агент: από + винительный

**Το βιβλίο γράφτηκε από έναν νέο συγγραφέα.** — Книга написана молодым писателем.
Инструмент — **με**: **γράφτηκε με μολύβι** — написано карандашом. Учёное **υπό** + род. — только в официальных текстах (B2/10).
В разговоре агента обычно переводят в актив: **Το έγραψε ένας νέος συγγραφέας.**

## Примеры

- **Η συνάντηση έχει αναβληθεί για την Τρίτη.** — Встреча перенесена на вторник.
- **Μέχρι τότε θα έχουν πουληθεί όλα τα εισιτήρια.** — К тому времени все билеты уже будут проданы.
- **Όταν έφτασα, είχαν ήδη ειπωθεί τα πιο σημαντικά.** — Когда я пришёл, самое важное уже было сказано.
- **Χτενίζεται μπροστά στον καθρέφτη.** — Она причёсывается перед зеркалом.
- **Αγαπιούνται πολύ.** — Они очень любят друг друга.
- **Χρειάζομαι βοήθεια.** — Мне нужна помощь.

## Типичные ошибки

- *έχω γραφτώ* → **έχω γραφτεί** — после έχω / είχα / θα έχω всегда -εί с ударением.
- *είναι γραφτεί, έχει γραμμένο* — смешаны две конструкции: **έχει γραφτεί** (действие) или **είναι γραμμένο** (состояние).
- *γράφτηκε με τον συγγραφέα* (калька с русского творительного) → **από τον συγγραφέα**; με — только инструмент.
- *Ντύνω γρήγορα* в значении «одеваюсь» → **ντύνομαι**; ντύνω — одевать кого-то: **ντύνω το παιδί**.
- У депонентов нет актива: нет *έρχω, *χρειάζω. Их аорист может быть «активным»: έρχομαι → **ήρθα**, κάθομαι → **κάθισα**.
- Взаимное значение принимают за пассив: **Φιλιούνται** — они целуются (друг с другом), а не «их целуют».
