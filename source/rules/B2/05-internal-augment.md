## Когда используется

Глаголы с учёной приставкой-предлогом (επι-, παρα-, κατα-, ανα-, απο-, δια-, μετα-, υπο-, περι-, προ-, συν-, εκ-) в аористе и имперфекте.
Приращение **ε-** встаёт **между приставкой и корнем**, а не в начало слова — если на него падает ударение.

## Образование

| Приставка + ε- | Результат | Пример |
|---|---|---|
| επι-, παρα-, κατα-, ανα-, απο-, δια-, μετα-, υπο- | конечная гласная выпадает | επι-τρέπω → **επ-έ-τρεψα** |
| περι-, προ- | гласная сохраняется | περι-γράφω → **περι-έ-γραψα** |
| συν- (συλ-, συμ-) | возвращается συν- | συλ-λαμβάνω → **συν-έ-λαβα** |
| εκ- | εκ- → εξ- | εκ-λέγω → **εξ-έ-λεξα** |
| корень на α- (άγω, άρχω) | α → η | εισ-άγω → **εισ-ή-γαγα** |

| Ενεστώτας | Αόριστος | Μέλλοντας Απλός | Значение |
|---|---|---|---|
| επιτρέπω | επέτρεψα | θα επιτρέψω | разрешать |
| επιστρέφω | επέστρεψα | θα επιστρέψω | возвращать(ся) |
| επαναλαμβάνω | επανέλαβα | θα επαναλάβω | повторять |
| αναλαμβάνω | ανέλαβα | θα αναλάβω | брать на себя |
| παραλαμβάνω | παρέλαβα | θα παραλάβω | получать (посылку) |
| συλλαμβάνω | συνέλαβα | θα συλλάβω | задерживать, арестовывать |
| συμβαίνει | συνέβη | θα συμβεί | случаться |
| εκλέγω | εξέλεξα | θα εκλέξω | избирать |
| εκπλήσσω | εξέπληξα | θα εκπλήξω | удивлять |
| υπογράφω | υπέγραψα | θα υπογράψω | подписывать |
| περιγράφω | περιέγραψα | θα περιγράψω | описывать |
| προβλέπω | προέβλεψα | θα προβλέψω | предвидеть |
| αποκτώ | απέκτησα | θα αποκτήσω | приобретать |
| εισάγω | εισήγαγα | — | импортировать, вводить |
| παράγω | παρήγαγα | — | производить |
| υπάρχω | υπήρξα (имперф. υπήρχα) | θα υπάρξω | существовать, быть |

**Безударное приращение исчезает**: επέτρεψα, επέτρεψες, επέτρεψε, **επιτρέψαμε, επιτρέψατε**, επέτρεψαν.
**В будущем и после να приращения нет**: θα επιτρέψω, να υπογράψεις.
Имперфект строится так же: **επέτρεπα, υπέγραφα, υπήρχε**.

Если ударение и так падает после приставки — приращения нет: υποστηρίζω → **υποστήριξα**, αποφασίζω → **αποφάσισα**.

## Регистр

Многие частые глаголы имеют и разговорный вариант с приращением на приставке:
υπόγραψα / **υπέγραψα**, περίγραψα / **περιέγραψα**, πρόβλεψα / **προέβλεψα**, πρόσφερα / **προσέφερα**, μετάφερα / **μετέφερα**, παράλαβα / **παρέλαβα**.
В письменной и официальной речи — внутреннее приращение. Только с ним: **συνέβη, εξέλεξα, επέτρεψα, συνέλαβα, εισήγαγα**.

## Примеры

- **Ο γιατρός δεν μου επέτρεψε να φάω γλυκά.** — Врач не разрешил мне есть сладкое.
- **Τι συνέβη χθες το βράδυ;** — Что случилось вчера вечером?
- **Η αστυνομία συνέλαβε δύο άτομα.** — Полиция задержала двух человек.
- **Υπέγραψα το συμβόλαιο σήμερα το πρωί.** — Я подписал договор сегодня утром.
- **Οι πολίτες εξέλεξαν νέο δήμαρχο.** — Горожане избрали нового мэра.
- **Παρέλαβα το δέμα από το ταχυδρομείο.** — Я получил посылку на почте.
- **Κανείς δεν προέβλεψε την κρίση.** — Никто не предвидел кризиса.

## Типичные ошибки

- *έπιτρεψα / επίτρεψα* → **επέτρεψα** — приращение внутри, после приставки.
- *επετρέψαμε* → **επιτρέψαμε** — безударное приращение пропадает.
- *θα επετρέψω, να υπέγραψω* → **θα επιτρέψω, να υπογράψω** — в будущем и после να основа без приращения.
- **κατάλαβα** (понял, καταλαβαίνω) ≠ **κατέλαβα** (захватил, καταλαμβάνω).
- *συμβαίνησε / συνέβηκε* → **συνέβη**; мн. ч. **συνέβησαν**.
- *εκλέξα* → **εξέλεξα** — εκ- перед гласной становится εξ-.
