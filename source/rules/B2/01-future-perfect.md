## Когда используется

- Действие **будет закончено к моменту в будущем**: «к восьми я уже закончу».
- **Предположение о прошлом**: «он, наверное, уже ушёл» — **θα έχει φύγει**.
- С **να** — завершённость к сроку или надежда на уже случившееся: πρέπει να έχεις τελειώσει, ελπίζω να έχει φτάσει.

## Образование

**θα + έχω** (в настоящем времени) + неизменяемая форма на **-ει** — та же, что в Παρακείμενος.

| Лицо | Актив | Пассив |
|---|---|---|
| εγώ | θα έχω γράψει | θα έχω γραφτεί |
| εσύ | θα έχεις γράψει | θα έχεις γραφτεί |
| αυτός, αυτή, αυτό | θα έχει γράψει | θα έχει γραφτεί |
| εμείς | θα έχουμε γράψει | θα έχουμε γραφτεί |
| εσείς | θα έχετε γράψει | θα έχετε γραφτεί |
| αυτοί, αυτές, αυτά | θα έχουν γράψει | θα έχουν γραφτεί |

Форма на -ει = Μέλλοντας Απλός 3 л. ед. ч. без θα:

| Μέλλοντας Απλός | Форма после έχω |
|---|---|
| θα τελειώσει | έχω τελειώσει |
| θα φύγει | έχω φύγει |
| θα πει | έχω πει |
| θα δει | έχω δει |
| θα φάει | έχω φάει |

С να: **να έχω γράψει, να έχεις τελειώσει, να έχει φτάσει**.

## Примеры

- **Μέχρι τις οκτώ θα έχω τελειώσει τη δουλειά.** — К восьми я уже закончу работу.
- **Όταν γυρίσεις, θα έχουμε φάει.** — Когда ты вернёшься, мы уже поедим.
- **Του χρόνου τέτοια εποχή θα έχει πάρει το πτυχίο του.** — В это время в следующем году он уже получит диплом.
- **Δεν απαντάει· θα έχει φύγει ήδη.** — Не отвечает — наверное, уже ушёл.
- **Θα έχεις ακούσει τα νέα.** — Ты, наверное, уже слышал новости.
- **Πρέπει να έχεις τελειώσει μέχρι την Παρασκευή.** — Ты должен закончить к пятнице.
- **Ελπίζω να έχει φτάσει.** — Надеюсь, он уже доехал.

## Маркеры

μέχρι / ως (+ срок), ως τότε, μέχρι να, πριν (να), ήδη, όταν + форма аориста (όταν έρθεις, όταν γυρίσεις)

## Типичные ошибки

- *θα έχω γράψω* ≠ **θα έχω γράψει** — после έχω всегда форма на -ει, она не спрягается: *θα έχουμε γράψουμε* → **θα έχουμε γράψει**.
- *θα έχω έγραψα* → **θα έχω γράψει** — приращение έ- здесь невозможно, основа как в θα γράψω.
- *Έχω τελειώσει μέχρι αύριο* — Παρακείμενος не говорит о будущем; для срока в будущем — **θα έχω τελειώσει**.
- **θα έχει φύγει** (наверное, уже ушёл — сейчас) ≠ **θα είχε φύγει** (ушёл бы / наверное, к тому моменту уже ушёл — в прошлом; см. B2/02).
- *Όταν θα έχεις τελειώσει, πες μου* → **Όταν τελειώσεις, πες μου** — после όταν, μόλις, αν нормативно ставится аористная основа без θα (как после να).
