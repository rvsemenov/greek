## Когда используется

«Этот, тот, такой», «каждый, весь», «кто-то, никто, что-то, ничего, никогда».

## Образование

### Указательные: αυτός (этот; он), εκείνος (тот)

Склоняются как прилагательные на -ος. **С существительным нужен артикль**: αυτός **ο** άντρας.

| | Мужской | Женский | Средний |
|---|---|---|---|
| им. ед. | αυτός / εκείνος | αυτή / εκείνη | αυτό / εκείνο |
| вин. ед. | αυτόν / εκείνον | αυτή(ν) / εκείνη(ν) | αυτό / εκείνο |
| род. ед. | αυτού / εκείνου | αυτής / εκείνης | αυτού / εκείνου |
| им. мн. | αυτοί / εκείνοι | αυτές / εκείνες | αυτά / εκείνα |
| вин. мн. | αυτούς / εκείνους | αυτές / εκείνες | αυτά / εκείνα |

**τέτοιος, -α, -ο** — такой: τέτοιο σπίτι. **τόσος, -η, -ο** — столько, такой (большой): τόσοι άνθρωποι.

### Количество

| Слово | Значение | Особенности |
|---|---|---|
| **κάθε** | каждый | не склоняется, с ед. ч.: κάθε μέρα, κάθε φορά |
| **καθένας, καθεμία, καθένα** | каждый (без существительного) | Καθένας έχει γνώμη. |
| **όλος, όλη, όλο** | весь | + артикль: όλη η οικογένεια, όλοι οι φίλοι |
| **μερικοί, μερικές, μερικά** | несколько, некоторые | μερικές φορές |
| **άλλος, άλλη, άλλο** | другой | την άλλη εβδομάδα |

### Неопределённые и отрицательные

| Утверждение («-то») | Отрицание / вопрос («ни-», «-нибудь») |
|---|---|
| **κάποιος, κάποια, κάποιο** — кто-то, какой-то | **κανένας (κανείς), καμία (καμιά), κανένα** — никто, ни один; кто-нибудь? |
| **κάτι** — что-то | **τίποτα** — ничего; что-нибудь? |
| **κάπου** — где-то, куда-то | **πουθενά** — нигде, никуда; где-нибудь? |
| **κάποτε** — когда-то, однажды | **ποτέ** — никогда; когда-нибудь? |

С глаголом отрицательные слова требуют **δεν / μην**: Δεν ήρθε κανείς. Без глагола — сами
по себе: **— Τι θέλεις; — Τίποτα.** В вопросе они значат «-нибудь»: **Θέλεις τίποτα;**

κανένας склоняется: вин. **κανέναν, καμία, κανένα**.

## Примеры

- **Αυτή η ταινία είναι πολύ ωραία.** — Этот фильм очень хороший.
- **Θυμάσαι εκείνο το εστιατόριο στην Πλάκα;** — Помнишь тот ресторан в Плаке?
- **Κάθε πρωί πίνω καφέ.** — Каждое утро я пью кофе.
- **Όλοι οι φοιτητές ήρθαν στο μάθημα.** — Все студенты пришли на занятие.
- **Κάποιος χτυπάει την πόρτα.** — Кто-то стучит в дверь.
- **Δεν ξέρω κανέναν εδώ.** — Я никого здесь не знаю.
- **Πήγες ποτέ στην Κρήτη;** — Ты когда-нибудь был на Крите?
- **Δεν πάμε πουθενά απόψε.** — Мы сегодня вечером никуда не идём.

## Типичные ошибки

- *αυτός άντρας, εκείνο σπίτι* ≠ **αυτός ο άντρας, εκείνο το σπίτι** — после указательного нужен артикль.
- *Ξέρω τίποτα* ≠ **Δεν ξέρω τίποτα** — при глаголе отрицательное слово требует δεν.
- *κάθε μέρες* ≠ **κάθε μέρα** — κάθε не склоняется и стоит с единственным числом.
- *Κάθε μέρα διάβαζα* в значении «я весь день читал» ≠ **Όλη τη μέρα διάβαζα** — κάθε = каждый, όλος = весь.
- *όλοι φίλοι* ≠ **όλοι οι φίλοι** — после όλος нужен артикль.
- *Δεν είδα κάποιον* (= не видел одного конкретного человека) ≠ **Δεν είδα κανέναν** (= никого не видел).
