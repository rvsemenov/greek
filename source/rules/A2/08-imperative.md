## Когда используется

Просьба, команда, совет. Как и в русском, два вида:
- **длительный** (от основы настоящего) — «делай» вообще, регулярно, продолжай: **Γράφε κάθε μέρα!**
- **совершенный** (от основы аориста) — «сделай» один раз, сейчас: **Γράψε μου ένα μήνυμα!**

Форма множественного числа — и для нескольких людей, и вежливое «вы»: **Περάστε, παρακαλώ.**

## Образование

### 1-е спряжение

| | Длительный: ед. / мн. | Совершенный: ед. / мн. |
|---|---|---|
| γράφω | γράφε / γράφετε | γράψε / γράψτε |
| διαβάζω | διάβαζε / διαβάζετε | διάβασε / διαβάστε |
| κλείνω | κλείνε / κλείνετε | κλείσε / κλείστε |
| ανοίγω | άνοιγε / ανοίγετε | άνοιξε / ανοίξτε |
| πληρώνω | πλήρωνε / πληρώνετε | πλήρωσε / πληρώστε |

Совершенный: основа аориста + **-ε** (ед. ч., ударение на 3-м слоге от конца) / **-τε** (мн. ч.).

### 2-е спряжение

| | Длительный: ед. / мн. | Совершенный: ед. / мн. |
|---|---|---|
| μιλάω (Β1) | μίλα / μιλάτε | μίλησε / μιλήστε |
| ρωτάω (Β1) | ρώτα / ρωτάτε | ρώτησε / ρωτήστε |
| περνάω (Β1) | πέρνα / περνάτε | πέρασε / περάστε |
| τηλεφωνώ (Β2) | — | τηλεφώνησε / τηλεφωνήστε |

У группы Β2 длительной формы практически нет — вместо неё **να + настоящее**: *Να οδηγείς προσεκτικά!*

### Неправильные (самые частые)

| Глагол | ед. / мн. | Глагол | ед. / мн. |
|---|---|---|---|
| έρχομαι | **έλα / ελάτε** | φέρνω | φέρε / φέρτε |
| λέω | **πες / πείτε** | παίρνω | πάρε / πάρτε |
| βλέπω | **δες / δείτε** | δίνω | δώσε / δώστε |
| τρώω | **φάε / φάτε** | κάνω | κάνε / κάντε |
| πίνω | **πιες / πιείτε** | βάζω | βάλε / βάλτε |
| βρίσκω | βρες / βρείτε | φεύγω | φύγε / φύγετε |
| μπαίνω | μπες / μπείτε | ανεβαίνω | ανέβα / ανεβείτε |
| βγαίνω | βγες / βγείτε | κατεβαίνω | κατέβα / κατεβείτε |
| πηγαίνω | πήγαινε / πηγαίνετε | κάθομαι | κάτσε / κάτσετε |
| ακούω | άκου / ακούτε; άκουσε / ακούστε | αφήνω | άφησε (άσε) / αφήστε (άστε) |

### Запрет: μη(ν) + να-форма без να

Отрицательного повелительного нет. Вместо него **μη(ν) + форма как после να**:

| Длительный | Совершенный |
|---|---|
| **Μη γράφεις!** — Не пиши (вообще)! | **Μη γράψεις!** — Не напиши (сейчас)! |
| **Μην ανησυχείς!** — Не волнуйся! (PDF, с. 20) | **Μην αργήσεις!** — Не опоздай! |

### Местоимения — после глагола

**Δώσε μου** — Дай мне. **Πες μου** — Скажи мне. **Φέρε το** — Принеси его. Подробнее — A2/10, B1/12.

## Примеры

- **Έλα εδώ!** — Иди сюда!
- **Κλείστε την πόρτα, παρακαλώ.** — Закройте дверь, пожалуйста.
- **Πες μου την αλήθεια.** — Скажи мне правду.
- **Φάε, θα κρυώσει!** — Ешь, остынет!
- **Μίλα πιο σιγά.** — Говори потише.
- **Μη φύγεις ακόμα!** — Не уходи ещё!

## Типичные ошибки

- *Μη γράψε! / Μην έλα!* ≠ **Μη γράψεις! / Μην έρθεις!** — запрет строится не от повелительного, а от να-формы.
- *Μου δώσε* ≠ **Δώσε μου** — при повелительном местоимение идёт после глагола.
- *Διαβάσε* ≠ **Διάβασε** — в ед. ч. ударение на 3-м слоге от конца; во мн. ч. — διαβάστε.
- *Πέσε μου* (= упади) ≠ **Πες μου** (= скажи мне) — от λέω форма πες.
- *Ελάστε* ≠ **Ελάτε**.
- *Μίλησε!* в значении «говори (давай, не молчи)» — это скорее **Μίλα!**; μίλησε = «поговори/скажи» один раз.
