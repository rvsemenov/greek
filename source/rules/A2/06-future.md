## Когда используется

| Μέλλοντας Συνεχής — «что буду делать?» | Μέλλοντας Απλός — «что сделаю?» |
|---|---|
| процесс или повторение в будущем | одно действие, результат |
| **Από αύριο θα ξυπνάω νωρίς.** — С завтрашнего дня буду вставать рано. | **Αύριο θα ξυπνήσω στις έξι.** — Завтра я проснусь в шесть. |

## Образование

- **Μέλλοντας Συνεχής = θα + настоящее время**: θα γράφω, θα αγαπώ (θα αγαπάω).
- **Μέλλοντας Απλός = θα + основа аориста + окончания настоящего** (-ω, -εις, -ει, -ουμε, -ετε, -ουν).
  Приращение έ- отпадает: έγραψα → γραψ- → **θα γράψω**.

| | γράφω | αγοράζω | αγαπώ (Β1) |
|---|---|---|---|
| εγώ | θα γράψω | θα αγοράσω | θα αγαπήσω |
| εσύ | θα γράψεις | θα αγοράσεις | θα αγαπήσεις |
| αυτός, αυτή, αυτό | θα γράψει | θα αγοράσει | θα αγαπήσει |
| εμείς | θα γράψουμε | θα αγοράσουμε | θα αγαπήσουμε |
| εσείς | θα γράψετε | θα αγοράσετε | θα αγαπήσετε |
| αυτοί, αυτές, αυτά | θα γράψουν | θα αγοράσουν | θα αγαπήσουν |

### Неправильные (от основы неправильного аориста, A2/02)

| Αόριστος | Μέλλοντας Απλός |
|---|---|
| είπα | θα πω, θα πεις, θα πει, θα πούμε, θα πείτε, θα πουν |
| είδα | θα δω, θα δεις, θα δει, θα δούμε, θα δείτε, θα δουν |
| ήπια | θα πιω, θα πιεις, θα πιει, θα πιούμε, θα πιείτε, θα πιουν |
| έφαγα | θα φάω, θα φας, θα φάει, θα φάμε, θα φάτε, θα φάνε |
| πήγα | θα πάω, θα πας, θα πάει, θα πάμε, θα πάτε, θα πάνε |
| ήρθα | θα έρθω, θα έρθεις, θα έρθει, θα έρθουμε, θα έρθετε, θα έρθουν |
| βγήκα, μπήκα, βρήκα | θα βγω, θα μπω, θα βρω (θα βγεις, θα βγει, θα βγούμε…) |
| πήρα | θα πάρω |

У είμαι и έχω одна форма: θα είμαι, θα έχω.

### Порядок слов

**δεν θα** + глагол; местоимение — между θα и глаголом: **Δεν θα σου τηλεφωνήσω.** — Я тебе не позвоню.

## Примеры

- **Θα σου στείλω ένα μήνυμα το βράδυ.** — Я пришлю тебе сообщение вечером.
- **Του χρόνου θα μένουμε στη Θεσσαλονίκη.** — В следующем году мы будем жить в Салониках.
- **Τι θα φας;** — Что ты будешь есть?
- **Δεν θα έρθω στο πάρτι.** — Я не приду на вечеринку.
- **Θα σε περιμένω στη στάση.** — Я буду ждать тебя на остановке.
- **Θα σας πω την αλήθεια.** — Я скажу вам правду.

## Маркеры

αύριο, μεθαύριο, του χρόνου, την άλλη εβδομάδα, σε δύο μέρες, σύντομα, αργότερα;
для Συνεχής: κάθε μέρα, από αύριο, πάντα, συχνά.

## Типичные ошибки

- *θα έγραψω* ≠ **θα γράψω** — в будущем приращения нет, окончания как в настоящем.
- *θα δεν έρθω* ≠ **δεν θα έρθω** — отрицание стоит перед θα.
- *θα λέξω, θα βλέψω, θα τρώσω* ≠ **θα πω, θα δω, θα φάω** — неправильные глаголы берут основу неправильного аориста.
- *θα πήρω, θα βγήκω* ≠ **θα πάρω, θα βγω**.
- *θα πιώ, θα δώ, θα πώ* ≠ **θα πιω, θα δω, θα πω** — односложные слова пишутся без ударения (но πείτε, δείτε — с ударением).
- *Κάθε μέρα θα γράψω* ≠ **Κάθε μέρα θα γράφω** — повторение → Συνεχής.
