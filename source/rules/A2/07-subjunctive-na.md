## Когда используется

В новогреческом нет инфинитива. Там, где в русском «хочу **купить**», «можешь **помочь**»,
«чтобы **успеть**», стоит **να + личная форма**. Глагол после να спрягается по лицу того,
кто действие выполняет.

## Образование

Формы те же, что в будущем времени, только вместо θα — **να**:

| Глагол | Длительный вид — основа настоящего («писать» регулярно) | Совершенный вид — основа аориста («написать» один раз) |
|---|---|---|
| γράφω | να γράφω, να γράφεις, να γράφει… | να γράψω, να γράψεις, να γράψει… |
| αγαπώ | να αγαπώ (να αγαπάω), να αγαπάς… | να αγαπήσω, να αγαπήσεις… |
| неправильные | να λέω, να βλέπω, να τρώω | να πω, να δω, να φάω, να πιω, να έρθω, να βγω, να βρω |

**Чаще нужен совершенный вид** (конкретное действие). Длительный — для привычки, процесса,
умения: **Πρέπει να διαβάζω κάθε μέρα** (PDF, с. 10) — Надо читать каждый день.

### Одно лицо или разные

| | |
|---|---|
| **Θέλω να φύγω.** — Я хочу уйти. | **Θέλω να φύγεις.** — Я хочу, чтобы ты ушёл. |
| **Μπορούμε να πάμε.** — Мы можем пойти. | **Πες του να έρθει.** — Скажи ему, чтобы пришёл. |

### Отрицание и местоимения

После να отрицание — **μην** (не δεν): **να μην αργήσεις**.
Слабое местоимение — между να (μην) и глаголом: **να το δω**, **να μην το ξεχάσεις**.

### После каких слов

θέλω να, μπορώ να, πρέπει να, ξέρω να (= умею), αρχίζω να, σταματάω να, προσπαθώ να,
ελπίζω να, μου αρέσει να; **για να** — цель («чтобы»).

## Примеры

- **Θέλω να μάθω ελληνικά.** — Я хочу выучить греческий.
- **Μπορείς να μου δώσεις το αλάτι;** — Можешь дать мне соль?
- **Θέλουμε να έρθεις μαζί μας.** — Мы хотим, чтобы ты пошёл с нами.
- **Πήγα στο φαρμακείο για να αγοράσω ασπιρίνες.** — Я пошёл в аптеку, чтобы купить аспирин.
- **Προσπάθησε να μην αργήσεις.** — Постарайся не опоздать.
- **Ξέρεις να κολυμπάς;** — Ты умеешь плавать?
- **Άρχισε να βρέχει.** — Начался дождь.

## Типичные ошибки

- *Θέλω αγοράσω* ≠ **Θέλω να αγοράσω** — без να нельзя, инфинитива нет.
- *Θέλω να πάω* в значении «хочу, чтобы ты пошёл» ≠ **Θέλω να πας** — второй глагол стоит в лице исполнителя.
- *να δεν έρθεις* ≠ **να μην έρθεις** — после να отрицание μην.
- *να έγραψα* ≠ **να γράψω** — без приращения, окончания настоящего.
- *για αγοράσω* ≠ **για να αγοράσω** — цель всегда για να.
- *Μπορώ να σε βοηθάω;* (конкретная помощь сейчас) ≠ **Μπορώ να σε βοηθήσω;** — один раз → основа аориста.
