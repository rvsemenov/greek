## Когда используется

Окончания -ομαι / -άμαι — это пассивная (медиопассивная) форма. На A2 важны три случая:

1. **Возвратное значение** («-ся»): ντύνω (одеваю) → **ντύνομαι** (одеваюсь), πλένω → **πλένομαι**.
2. **Депоненты** — глаголы, у которых есть только эта форма, а значение активное:
   **έρχομαι** (прихожу), **κάθομαι** (сижу), **σκέφτομαι** (думаю), **θυμάμαι** (помню).
3. Настоящий пассив («пишется», «продаётся») — тот же набор окончаний; подробнее B1/03.

## Образование

| | -ομαι: έρχομαι | -άμαι: θυμάμαι |
|---|---|---|
| εγώ | έρχομαι | θυμάμαι |
| εσύ | έρχεσαι | θυμάσαι |
| αυτός, αυτή, αυτό | έρχεται | θυμάται |
| εμείς | **ερχόμαστε** | **θυμόμαστε** |
| εσείς | έρχεστε (ερχόσαστε) | θυμάστε (θυμόσαστε) |
| αυτοί, αυτές, αυτά | έρχονται | **θυμούνται** |

### Частые глаголы

| На -ομαι | | На -άμαι | |
|---|---|---|---|
| έρχομαι | приходить | θυμάμαι | помнить |
| κάθομαι | сидеть, садиться | φοβάμαι | бояться |
| σκέφτομαι | думать | κοιμάμαι | спать |
| χρειάζομαι | нуждаться | λυπάμαι | сожалеть, жалеть |
| γίνομαι | становиться | | |
| εργάζομαι | работать | | |
| κουράζομαι | уставать | | |
| ξεκουράζομαι | отдыхать | | |
| σηκώνομαι | вставать | | |
| ντύνομαι | одеваться | | |
| λέγομαι | называться, зваться | | |
| βρίσκομαι | находиться | | |

Длительное будущее и να-форма — с теми же окончаниями: **θα έρχομαι**, **να κάθεσαι**.
Совершенные формы (θα έρθω, να καθίσω, να σκεφτώ, να θυμηθώ) — B1/03, B1/13.
Есть ещё типы -ιέμαι и -ούμαι (αγαπιέμαι, θεωρούμαι) — B2/04.

## Примеры

- **Από πού έρχεσαι;** — Откуда ты (идёшь / родом)?
- **Πώς λέγεσαι; — Λέγομαι Άννα.** — Как тебя зовут? — Меня зовут Анна.
- **Χρειάζομαι βοήθεια.** — Мне нужна помощь.
- **Δεν θυμάμαι το όνομά του.** — Я не помню его имени.
- **Φοβάσαι τα σκυλιά;** — Ты боишься собак?
- **Τα παιδιά κοιμούνται.** — Дети спят.
- **Σκέφτομαι να αλλάξω δουλειά.** — Я думаю сменить работу.

## Типичные ошибки

- *Φοβάμαι των σκύλων* ≠ **Φοβάμαι τα σκυλιά** — после φοβάμαι, θυμάμαι, χρειάζομαι — винительный, а не родительный, как в русском.
- *έρχομαστε, θυμάμαστε* ≠ **ερχόμαστε, θυμόμαστε** — в 1-м л. мн. ч. ударение на -ό-.
- *θυμάνται* ≠ **θυμούνται** — 3-е л. мн. ч. у -άμαι на -ούνται.
- *έρχεστε* (вы приходите) и **έρχεται** (он приходит) — разные формы: -στε ≠ -ται.
- *Ντύνω γρήγορα* в значении «я быстро одеваюсь» ≠ **Ντύνομαι γρήγορα** — ντύνω = одеваю кого-то.
- *Πώς λέγεις;* ≠ **Πώς λέγεσαι;** (или **Πώς σε λένε;**) — «как тебя зовут».
