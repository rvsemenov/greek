## Когда используется

Значение то же, что у правильного аориста (A2/01): одно законченное действие в прошлом.
Но основа у этих глаголов не строится по правилу σ/ξ/ψ — её учат вместе с глаголом.
Будущее совершенное и να-форма строятся от этой же основы: είπα → θα πω, να πω.

## Образование

### 1. Другой корень

| Ενεστώτας | Αόριστος | Μέλλοντας Απλός | |
|---|---|---|---|
| λέω | είπα | θα πω | говорить → сказал |
| βλέπω | είδα | θα δω | видеть → увидел |
| τρώω | έφαγα | θα φάω | есть → поел |
| έρχομαι | ήρθα | θα έρθω | приходить → пришёл |
| πηγαίνω / πάω | πήγα | θα πάω | идти → пошёл |

### 2. Аорист на -ηκα (без приращения!)

| Ενεστώτας | Αόριστος | Μέλλοντας Απλός | |
|---|---|---|---|
| βγαίνω | βγήκα | θα βγω | выходить |
| μπαίνω | μπήκα | θα μπω | входить |
| βρίσκω | βρήκα | θα βρω | находить |
| ανεβαίνω | ανέβηκα | θα ανέβω | подниматься |
| κατεβαίνω | κατέβηκα | θα κατέβω | спускаться |

### 3. Основа меняется, окончание -α без σ/ξ/ψ

| Ενεστώτας | Αόριστος | Μέλλοντας Απλός | |
|---|---|---|---|
| παίρνω | πήρα | θα πάρω | брать |
| μαθαίνω | έμαθα | θα μάθω | учить, узнавать |
| καταλαβαίνω | κατάλαβα | θα καταλάβω | понимать |
| φεύγω | έφυγα | θα φύγω | уходить, уезжать |
| βάζω | έβαλα | θα βάλω | класть, ставить |
| βγάζω | έβγαλα | θα βγάλω | вынимать, снимать |
| φέρνω | έφερα | θα φέρω | приносить |
| πίνω | ήπια | θα πιω | пить |
| δίνω | έδωσα | θα δώσω | давать |
| κάνω | έκανα | θα κάνω | делать |
| πέφτω | έπεσα | θα πέσω | падать |
| μένω | έμεινα | θα μείνω | жить, оставаться |
| στέλνω | έστειλα | θα στείλω | посылать |
| πλένω | έπλυνα | θα πλύνω | мыть |
| περιμένω | περίμενα | θα περιμένω | ждать |
| ζεσταίνω | ζέστανα | θα ζεστάνω | греть |

### 4. Глаголы на гласную + -ω (PDF, с. 14)

ακούω → άκουσα, κλαίω → έκλαψα, καίω → έκαψα, φταίω → έφταιξα.

### Нет аориста

είμαι → **ήμουν** (одна форма прошедшего), έχω → **είχα**, ξέρω → **ήξερα**.

### Приращение во множественном числе

| | είπα | ήρθα | ήπια | έφαγα |
|---|---|---|---|---|
| εμείς | είπαμε | ήρθαμε | ήπιαμε | **φάγαμε** |
| εσείς | είπατε | ήρθατε | ήπιατε | **φάγατε** |
| αυτοί | είπαν | ήρθαν | ήπιαν | έφαγαν |

Начальные **ει-** и **ή-** у είπα, είδα, ήρθα, ήπια не отпадают; обычное έ- отпадает: έφαγα → φάγαμε, έμαθα → μάθαμε.

## Примеры

- **Τι είπες;** — Что ты сказал?
- **Είδαμε μια ωραία ταινία.** — Мы посмотрели хороший фильм.
- **Πότε ήρθες στην Ελλάδα;** — Когда ты приехал в Грецию?
- **Βγήκα από το σπίτι στις επτά.** — Я вышел из дома в семь.
- **Δεν κατάλαβα την ερώτηση.** — Я не понял вопрос.
- **Ήπια έναν καφέ και έφυγα.** — Я выпил кофе и ушёл.
- **Πού βρήκες αυτό το βιβλίο;** — Где ты нашёл эту книгу?

## Типичные ошибки

- *έλεξα, έβλεψα, έτρωσα* ≠ **είπα, είδα, έφαγα** — у λέω, βλέπω, τρώω аорист от другого корня.
- *έβγηκα, έμπηκα, έβρηκα* ≠ **βγήκα, μπήκα, βρήκα** — у аористов на -ηκα приращения нет, хотя слога два.
- *εφάγαμε* ≠ **φάγαμε**, но **ήρθαμε, ήπιαμε, είπαμε** — ει-/ή- часть основы, они остаются.
- *θα βγήκω, θα βρήκω* ≠ **θα βγω, θα βρω** — в будущем -ηκ- исчезает.
- *θα πήρω* ≠ **θα πάρω** — в будущем другой гласный: πήρα, но θα πάρω.
- *πήγαινα* в значении «пошёл» ≠ **πήγα** — πήγαινα это παρατατικός («ходил, шёл»).
