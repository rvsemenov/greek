## Когда используется

Аорист («что сделал?») глаголов 2-го спряжения — с ударением на окончании:
группа **Β1** (-άω/-ώ: αγαπάω, μιλάω) и группа **Β2** (-ώ/-είς: μπορώ, τηλεφωνώ).
В PDF это «2 спряжение В1 / В2» — это группы, а не уровни.

## Образование

Основной вариант (как в PDF): **основа + ησ + -α, -ες, -ε, -αμε, -ατε, -αν**.
У части глаголов вместо ησ стоит ασ, εσ или ξ (таблица ниже). Ударение на 3-м слоге от конца.

| | αγαπώ (Β1) | μπορώ (Β2) |
|---|---|---|
| εγώ | αγάπησα | μπόρεσα |
| εσύ | αγάπησες | μπόρεσες |
| αυτός, αυτή, αυτό | αγάπησε | μπόρεσε |
| εμείς | αγαπήσαμε | μπορέσαμε |
| εσείς | αγαπήσατε | μπορέσατε |
| αυτοί, αυτές, αυτά | αγάπησαν | μπόρεσαν |

### Какой суффикс

| Суффикс | Группа Β1 (-άω) | Группа Β2 (-ώ, -είς) |
|---|---|---|
| **-ησα** (большинство) | μιλάω → μίλησα, ρωτάω → ρώτησα, απαντάω → απάντησα, βοηθάω → βοήθησα, ξυπνάω → ξύπνησα, νικάω → νίκησα | οδηγώ → οδήγησα, τηλεφωνώ → τηλεφώνησα, προσπαθώ → προσπάθησα, συμφωνώ → συμφώνησα, ανησυχώ → ανησύχησα, εξηγώ → εξήγησα |
| **-ασα** | γελάω → γέλασα, πεινάω → πείνασα, διψάω → δίψασα, χαλάω → χάλασα, χαμογελάω → χαμογέλασα, σπάω → έσπασα | — |
| **-ασα** с изменённой основой | ξεχνάω → ξέχασα, περνάω → πέρασα, κερνάω → κέρασα | — |
| **-εσα** | φοράω → φόρεσα, πονάω → πόνεσα | μπορώ → μπόρεσα, καλώ → κάλεσα, παρακαλώ → παρακάλεσα, συγχωρώ → συγχώρεσα, αποτελώ → αποτέλεσα, εκτελώ → εκτέλεσα |
| **-ηξα / -αξα** | πηδάω → πήδηξα, φυσάω → φύσηξα, τραβάω → τράβηξα; πετάω → πέταξα | — |

Правило: **-ησα** по умолчанию, остальные группы учатся списком.

Приращение έ- — только у двусложных: ζω → **έ**ζησα, σπάω → **έ**σπασα.

Будущее и να-форма — от той же основы: θα αγαπήσω, θα γελάσω, θα μπορέσω, θα πετάξω.

## Примеры

- **Μίλησα με τον διευθυντή.** — Я поговорил с директором.
- **Ποιος σου τηλεφώνησε;** — Кто тебе позвонил?
- **Γελάσαμε πολύ.** — Мы очень посмеялись.
- **Ξέχασα τα κλειδιά μου.** — Я забыл ключи.
- **Δεν μπόρεσα να έρθω.** — Я не смог прийти.
- **Κάλεσα τους φίλους μου για φαγητό.** — Я пригласил друзей на обед.
- **Έζησε δέκα χρόνια στην Αθήνα.** — Он прожил десять лет в Афинах.

## Типичные ошибки

- *αγαπούσα* в значении «полюбил» ≠ **αγάπησα** — αγαπούσα это παρατατικός («любил»).
- *γέλησα, πείνησα* ≠ **γέλασα, πείνασα** — у этих глаголов -ασα, а не -ησα.
- *ξέχνησα, πέρνασα* ≠ **ξέχασα, πέρασα** — у ξεχνάω, περνάω, κερνάω пропадает -ν-.
- *μπόρησα, κάλησα* ≠ **μπόρεσα, κάλεσα** — группа на -εσα.
- *πέτησα* ≠ **πέταξα**, *πήδησα* ≠ **πήδηξα** — особые аористы на -ξα.
- *ένικησα* ≠ **νίκησα** — приращение только у двусложных (έζησα).
